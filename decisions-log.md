## Decision Register

### D-01: Partner Naming Convention
- **Question:** Fernao rebranded to Axians (VINCI Energies). Which name throughout?
- **Decision:** "Axians (formerly Fernao)" on first mention per document, then "Axians" thereafter
- **Rationale:** Forward-looking but historically accurate. Fernao name preserved where referencing pre-rebrand events.

### D-02: Language — All Artifacts
- **Question:** Original spec called for German email sequences
- **Decision:** All English — emails, business cases, MAPs, showcase, everything
- **Rationale:** Portfolio showcase for international audience; English demonstrates strategic thinking more broadly

### D-03: Intent Signal Integration
- **Question:** How prominent should the PIP (Partner Intelligence Program) concept be in targeting?
- **Decision:** Light touch — explain the concept at the top of Stage 1 section, but scoring matrix uses firmographic criteria only. Intent marked as 🧠 hypothesis.
- **Rationale:** Cannot verify actual 6sense signals; the concept demonstrates strategic thinking without overclaiming

### D-04: Akamai Content Scope
- **Question:** What Akamai content to collect in Stage 0?
- **Decision:** Guardicore-specific only — datasheets, case studies, OT whitepapers, manufacturing references
- **Rationale:** Sprint is focused on one product motion; broader Akamai portfolio is noise

### D-05: Axians Brand Guidelines
- **Question:** No public brand-book exists. How to handle branded PDFs?
- **Decision:** Research actual brand from website, PDFs, social media, event materials. Codify findings as a working style guide (colors, typography, tone, visual patterns).
- **Rationale:** Authentic branding over generic design; shows attention to partner relationship

### D-06: Audience Framing
- **Question:** Who reads the final output?
- **Decision:** Portfolio showcase first, but structured to be usable if opportunity arises
- **Rationale:** Dual-purpose drives higher quality; hypothesis disclaimers keep it honest

### D-07: Stage 4 Output Format
- **Question:** Format for execution arsenal (email sequences, business cases, MAPs)
- **Decision:** PDF — Axians-branded design
- **Rationale:** Portfolio hero pieces need visual polish; PDFs are the presentation format

### D-08: KPI Dashboard Format
- **Question:** Format for measurement system
- **Decision:** Interactive HTML
- **Rationale:** Demonstrates technical capability; interactive elements show data thinking

### D-09: CRM Research Approach
- **Question:** Which CRM does Axians use?
- **Decision:** Research creatively — job postings (historical), website HTML source code for tracking scripts, OSINT
- **Rationale:** Real CRM identification makes the spec actionable, not hypothetical

### D-10: PDF Visual Identity
- **Question:** Whose brand on the execution PDFs?
- **Decision:** Axians-branded — as if produced internally by Axians
- **Rationale:** Demonstrates partner-first thinking; shows what a real partner enablement kit looks like

### D-11: Review Checkpoints
- **Question:** How many stops during execution?
- **Decision:** Two checkpoints only: after Stage 1 (targeting approval) and after Stage 4 (execution review)
- **Rationale:** Balances oversight with execution speed; 43 files need momentum
