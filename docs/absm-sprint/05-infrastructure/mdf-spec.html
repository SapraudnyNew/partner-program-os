MDF Specification — Axians ABSM Program

MDF = Market Development Funds. Akamai allocates MDF to partners to co-fund marketing activities. This spec defines how MDF is used in the ABSM program.

Budget allocation

Activity Estimated cost MDF % Axians %
Account research + AI pipeline €2,000 100% 0%
Collateral production (8 PDFs) €4,000 75% 25%
Technical workshops (4 accounts) €3,200 50% 50%
POC infrastructure (2 POCs) €4,000 50% 50%
it-sa Nürnberg joint booth contribution €5,000 50% 50%
Total program budget ~€18,200 ~60% ~40%

MDF claim process

  1. Pre-approval: Submit activity plan + budget to Akamai DACH partner team before activation
  2. Execution: Complete activity, retain all receipts and invoices
  3. Claim submission: Submit via Akamai Partner Hub within 30 days of activity completion
  4. Documentation required: Activity proof (photos, attendance lists, reports), invoice, ROI metrics

MDF governance rules

  • MDF must be used for customer-facing activities (not Axians internal training)
  • Each activity requires pre-approval — no retroactive MDF claims
  • ROI reporting is mandatory: MDF-funded activities must report pipeline generated
  • MDF unused within the quarter is forfeited

Expected ROI

Target metric: Pipeline generated per €1,000 MDF spent
Baseline assumption: 1 technical briefing = 1 opportunity = €50–200K ARR potential
Program target: €400K qualified pipeline from €10K MDF investment = 40× ROI
