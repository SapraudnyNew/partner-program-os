The 80+ Information Security Coordinators Network

Confirmed in Trumpf’s public data security page: “They are supported by a well-organized network of over 80 information security coordinators who provide them with rules and guidelines.“

This is notable: Trumpf has a distributed cyber org where each business unit/division has at least one dedicated information security coordinator. For a Guardicore rollout, this network is the implementation layer — each coordinator would need to understand the segmentation policy for their zone.

For comparison: Hörmann (CISO + IT subsidiary MD), Reinhausen (Feyrer), Witte (Schwarz + Heisig + Demant) — none has this level of organizational depth.
