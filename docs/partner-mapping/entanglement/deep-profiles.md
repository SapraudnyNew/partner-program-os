## Profile 6: Computacenter DACH

**Disposition:** Contain  
**Size:** ~£5B global revenue, significant DACH share ✅  
**Illumio:** MSP partner ✅ — creates conflict at microsegmentation layer  
**Akamai:** Select tier ✅ — significantly under-tiered for footprint  
**Key insight:** Computacenter is the clearest tier mismatch in the DACH landscape. Global scale, minimal Akamai investment. The Contain play is an upgrade conversation, not a new recruitment.

## Profile 7: Bechtle AG

**Disposition:** Contain  
**Size:** ~€6B revenue, Germany's largest IT reseller ✅  
**Primary stack:** Cisco Gold + Palo Alto Gold ✅  
**Illumio:** Not present ✅  
**Akamai:** Existing relationship, tier unclear ⚠️  
**Key insight:** Scale makes Bechtle attractive, but their Cisco/PANW primary relationships create inertia. Guardicore co-sell is possible on large enterprise accounts where the network layer is already Cisco.

## Profile 8: DT Security (T-Systems Cybersecurity)

**Disposition:** Contain  
**Parent:** Deutsche Telekom AG ✅  
**Focus:** Zscaler-first SASE architecture ✅  
**Akamai:** WAF/CDN relationship ✅  
**Guardicore:** Selective only — on-premises data centre accounts where Zscaler doesn't cover east-west  
**Key insight:** DT Security is not a volume partner for Guardicore. One or two named accounts per year is the realistic expectation.
