# ADR-006: Akamai HVO Positioning — Warm Referral, Bait-and-Switch

**Date:** 2026-05-14
**Status:** Accepted

## Decision

The Akamai HVO is built for a **warm referral path**, not cold outreach. The document is a **leave-behind memo** the referrer uses to advocate Alex internally — not a value letter sent over LinkedIn.

Positioning uses **bait-and-switch**: present at Senior Manager level (the actual role), signal capability to skip-level reader (VP / Director) who reads the same document.

## Context

The Akamai posting: Senior Channel Marketing Manager, DACH region, Zero Trust security.

Alex profile: 20+ years pan-European B2B sales and P&L leadership, multi-country partner program experience.

This is a **level mismatch**. Three options:

1. **Take role as written.** Submit standard application as Senior Manager. Risk: HR cattle-call, no signal of strategic capacity, undersells Alex.
2. **Reframe upward.** Pitch as Director / Head of Channel EMEA. Risk: scares the hiring manager. Threatens their authority. Likely silent decline.
3. **Bait-and-switch through warm referral.** Enter through the posted role (the door that's actually open) via the existing referrer. Document signals manager-grade fit *and* exec-grade thinking, so it can travel up the org without Alex asking it to.

Alex's situation strongly favors option 3: a trusted referrer has already said "they will at least take a call."

## Resolution

### What this changes about the HVO

A warm-referral leave-behind has a fundamentally different shape than a cold value letter.

| Property | Cold value letter | Warm referral leave-behind |
|---|---|---|
| Reader | Hiring manager, first contact | Hiring manager *after* referrer has primed them |
| Tone | "Here's why you should talk to me" | "Here's what we'd actually do together" |
| Length | One page | 3-5 pages, with sections |
| Structure | Hook → proof → ask | Context → diagnosis → plan → fit |
| Call to action | "30 min call?" | None — referrer handles scheduling |
| Internal travel | Stays with hiring manager | Designed to be forwarded up |

### Bait-and-switch mechanics

Three signals must coexist in the same document:

**Manager-grade signals (for hiring manager):**
- Specific tactical detail (TO/WITH/THROUGH/FOR channel marketing)
- DACH region knowledge
- Zero Trust security context
- Practical 90-day plan

**Executive-grade signals (for VP/Director skim):**
- Strategic frame (orchestrator vs participant in Akamai's ecosystem)
- P&L thinking ("partner-sourced pipeline → revenue per FTE")
- Cross-functional choreography (alignment with sales, product marketing, customer success)
- Business case framing in EUR, not just MQL

### What this is NOT

- Not a CV.
- Not a cover letter.
- Not a request for an interview.
- Not a Crossbeam-style ELG manifesto (Akamai isn't a SaaS partnership platform — it's a security vendor with DACH channel reality).

## Consequences

- The referrer must approve the document before any handoff. The referrer's credibility is on the line.
- Talking points file (`02-akamai/02-talking-points.md`) is written separately, for Alex to use in the live call. Different rhythm than the leave-behind.
- If a different role / referrer combo emerges, this approach is replicable. The pattern is reusable.
