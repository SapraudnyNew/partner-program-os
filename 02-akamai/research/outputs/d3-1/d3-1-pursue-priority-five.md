### Akamai fit assessment

**Product-gap analysis:** Das Axians-Portfolio hat eine explizite "Mikrosegmentierung"-Lücke: Axians nennt Mikrosegmentierung als Managed-Service-Angebot (axians.de/portfolio/cyber-security/managed-security-services), betreibt aber kein bekanntes Mikrosegmentierungsprodukt. Die eigene smartSOC MDRS-Lösung basiert auf WatchGuard — kein nativer Mikrosegmentierungsansatz. **Akamai Guardicore Segmentation** füllt diese Lücke präzise. Zudem hat Axians starke OT-/ICS-Kompetenz (ISG Leader OT Security) — Akamai Guardicore deckt OT-Segmentierung ab.

**API Security:** Axians betreibt Cloud-Infrastrukturen für Kunden und bietet WAF an, aber kein dezidiertes API Security-Produkt ist erkennbar. **Akamai API Security** ist ein natürlicher Erweiterungskandidat.

**DDoS/CDN:** Axians bietet keine Akamai-Konkurrenzprodukte (kein Cloudflare, kein Imperva in Stack sichtbar). **Akamai Prolexic/Kona** könnte als ergänzende Komponente in MSS-Paketen positioniert werden.

**Named-account overlap hypothesis:**

- **Hochland SE** (Lebensmittelproduktion) — NIS2 Sektor "Nahrungsmittel" — direktes Überschneidungspotenzial ✅
- **IAV GmbH** (Automotive Engineering) — kritische F&E-Daten, erweiterter NIS2-Scope → Segmentierung ✅
- **Flughafen München**afen München** — KRITIS Kategorie 1 → Akamai DDoS + Guardicore ✅
- **Autoteile-Zulieferer (anonym)** — OT-Segmentierung bereits im Gange → Erweiterung auf IT-Mikrosegmentierung ✅
- Alle Axians-Managed-SOC-Kunden in Energie, Gesundheit, öffentlicher Sektor sind NIS2-verpflichtet

**Outreach hook:**

*"Axians ist ISG Leader für Next-Gen SOC/MDR — aber die Mikrosegmentierung als letztes Verteidigungselement fehlt im Stack. Akamai Guardicore komplettiert das '360° Cyber Security'-Versprechen, das Axians gegenüber Kunden macht — besonders in OT/IT-konvergenten Umgebungen, wo Axians bereits stark ist. Der it-sa-Auftritt zeigte kein Mikrosegmentierungsprodukt. Jetzt, nach Abschluss der Fernao-Integration, ist der Zeitpunkt ideal, das kombinierte Portfolio zu stärken."*

### Akamai fit assessment

**Product-gap analysis:** SVA hat einen Fortinet-zentrischen Stack (EPSP-Status, OT Partner of the Year) — sehr stark in Perimeter-Security, NGFW, OT. **Fehlend:** Mikrosegmentierung (kein Guardicore, kein Illumio sichtbar), API Security, Application-Layer DDoS. **Named-account overlap hypothesis:**

- Bundeswehr/BWI — KRITIS, sensible Infrastruktur → Guardicore Segmentierung hochrelevant
- Bundesbehörden allgemein (BAMF, ITZBund) → Akamai App & API Security / Bot Management
- Stadt Haldensleben und ähnliche Kommunen → NIS2 kommunale Verwaltung Scope
- Mittelstandskunden in Sachsen (SID-Ökosystem) → NIS2-betroffene öffentliche Einrichtungen

**Outreach hook:**

*"SVA ist der erste und einzige Fortinet EPSP in Deutschland — das ist ein starkes Alleinstellungsmerkmal. Aber Kunden wie die Bundeswehr oder KRITIS-Betreiber brauchen mehr als Perimeter-Security: Mikrosegmentierung und Application Security sind die natürliche Erweiterung. Akamai Guardicore arbeitet herstellerneutral — auch im Fortinet-Umfeld. Für das mSOC by SVA wäre Guardicore das fehlende Puzzle-Stück zwischen NDR (Vectra) und der Endpunktsicherung (SentinelOne)."*
